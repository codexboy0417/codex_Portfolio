# Ashit Upadhyay — Portfolio

> Immersive spatial portfolio designed and built for **Ashit Upadhyay** (`codexboy_04`), 3rd-year B.Tech AI & ML student at Vishveshwarya Group of Institutions.

Live URL: [ashit-upadhyay.vercel.app](https://ashit-upadhyay.vercel.app)

---

## 🚀 Overview

A single-page, scroll-based cinematic portfolio engineered with a spatial 3-layer scene model:
1. **Fixed Environment Layer** — Pure black background room tone.
2. **Ambient Particle Canvas Field** — Subtle atmospheric depth cues and canvas text intro assembly.
3. **Scrollable Interface** — Hologram interface featuring inertia RAF scrolling, typography contrast, and interactive cards.

---

## 🛠️ Tech Stack

- **Framework**: [Astro 5](https://astro.build/) (Static Site Generation / SSG)
- **UI Islands**: [React 18](https://react.dev/)
- **Styling**: [Tailwind CSS 4](https://tailwindcss.com/) with `@tailwindcss/vite`
- **Motion & FX**: [Motion](https://motion.dev/) (Framer Motion v12) `<LazyMotion features={domAnimation}>`
- **Typography**: `@fontsource/playfair-display`, `@fontsource/dm-sans`, `@fontsource/dm-mono`
- **Icons**: [Lucide React](https://lucide.dev/)
- **Bundler**: [Vite 6](https://vitejs.dev/)
- **Deployment & Analytics**: [Vercel](https://vercel.com/) with `@vercel/analytics` and `@vercel/speed-insights`
